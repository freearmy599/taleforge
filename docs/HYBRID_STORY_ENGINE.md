# TaleForge Hybrid Story Engine

The Hybrid Story Engine is a structural reasoning layer, not a prose generator.

## Inputs
- genre taxonomy
- narrative traditions
- narrative modes
- trope library
- genre grammars
- compatibility graph

## Responsibilities
1. Validate whether selected components can coexist.
2. Identify a primary grammar and supporting grammars.
3. Preserve structural constraints from each component.
4. Record conflicts and resolution rules.
5. Estimate novelty potential and structural risk.
6. Produce a reusable recipe for later Novelty, Inversion, Opportunity and Story Architecture systems.

## Non-responsibilities
- It does not write chapters.
- It does not rewrite existing canon.
- It does not imitate individual authors.
- It does not decide whether a current published story should be changed.

## Pipeline
Validated components -> Compatibility -> Hybrid Recipe -> Novelty -> Inversion -> Story Opportunity -> Story Concept -> Story DNA.
